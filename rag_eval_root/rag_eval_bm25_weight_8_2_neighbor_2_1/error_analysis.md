补充定位方式：

- 这个 Top20 只用于判断 gold/答案是否进入宽候选池；由于当前 `top_k` 会影响 scene expansion 截断，不能拿它的 Recall@5 和正式 Top5 直接比较。

## 总体结论

5 个错误样例里，核心问题不是单纯 BM25 能力不足，而是三类问题叠加：

| 错误类型 | 数量 | 是否继续优化召回 | 说明 |
| --- | ---: | --- | --- |
| 正确 chunk/答案在宽候选或 BM25 路内，但没有进入最终 Top5 | 5 | 是 | 当前融合后再 scene expansion，容易让 dense 高分同质场景吃满 Top5。 |
| gold 标注偏移或不准 | 3 | 先修评测集，再优化召回 | `book-000075`、`book-000112`、`book-000007` 均不是最直接答案 chunk。 |
| 正确答案在同 scene 相邻位置 | 2 | 是 | 需要改 scene expansion 的打包方式，而不是简单扩大邻居。 |
| 用户问题过于模糊 | 1 | 后续优化 | “小说片段中/异常现象”缺少实体或事件锚点。 |
| 问题实体别名没识别 | 0 | 暂不优先 | 当前 5 个 miss 不是别名主因。 |
| 答案需要跨章节综合 | 0 | 暂不优先 | 当前没有多跳综合型失败。 |
| 原文没有明确答案 | 0 | 不属于当前问题 | 当前答案在原文中都有明确依据。 |

如果目标是 `Recall@5 >= 90%`，当前只差 1 个样例。最小有效方向不是继续调 BM25 权重，而是先修 gold 标注，同时改“候选保留/Top5 打包”。

## 后续提升方向

### 1. 先修评测集 gold 标注

建议先修这 3 条，否则指标会把“标注偏移”误判成召回失败：

| 问题 | 当前 gold | 建议 gold |
| --- | --- | --- |
| 赞特港货币兑换 | `book-000075` | `book-000077` |
| 基斯对话异常现象 | `book-000112` | `book-000113` |
| 艾莉丝外号 | `book-000007` | `book-000008` 或 `book-000009` |

这一步不是模型优化，但会让评测更可信。尤其当前只差 1 个样例到 90%，gold 偏移会明显干扰方向判断。

### 2. 保留两路召回 seed，而不是融合后直接截断

当前失败最明显的问题是：BM25 明明命中，但 8:2 分数融合后，BM25-only 或 BM25-strong 的 chunk 仍可能排不到 scene expansion 的候选前列。

建议最小改动：

- dense top20 和 BM25 top20 先各自保留 seed。
- scene expansion 时从两路 seed 的并集建候选，不要只看融合后的前 `vector_top_n`。
- 最终 Top5 再按融合分排序或打包。

这样对第 1、2、4、5 条都有直接帮助，而且不引入 rerank、HyDE、多 query 等新模块。

### 3. 改 Top5 打包策略：seed 优先，邻居补充

现在的 Top5 容易被一个场景连续 chunk 吃满。更稳的方式是：

- 先放入每个高分 seed chunk 本身。
- 再补它的前后邻居。
- 如果 Top5 空间不足，优先保留不同 seed，而不是优先展开同一个 scene。

这和之前测试过的“简单 scene diversity cap”不同。diversity cap 是硬砍场景，容易伤害连续答案；seed-first packing 是先保证多路召回的核心命中不被邻居挤掉。

### 4. 后续再做轻量 rerank

如果允许再进一步优化，最有效的是对最终候选 20 个做轻量 rerank。当前 5 个 miss 里至少 3 个属于“候选已出现但排序没进 Top5”，rerank 比继续调权重更可能提升。

可先做非 LLM rerank：

- query 关键词覆盖率。
- 稀有词命中数。
- 问题类型线索，例如“是谁/哪些/多少/如何”对应人名、数量、动作描述。
- BM25 rank 与 dense rank 的 reciprocal rank fusion。

这一步预计主要修第 2、3、5 条。

## 优先级建议

1. 修正 3 条 gold 标注，重新跑同一数据集。
2. 改两路 seed 保留：dense top20 + BM25 top20 都进入 scene expansion 候选池。
3. 改 Top5 打包为 seed-first，再补邻居。
4. 如果还没过 90%，再加轻量 rerank。

当前不建议优先做：

- 实体别名增强：这 5 条没有明显别名失败。
- 章节摘要/多跳：这 5 条不是跨章节综合问题。
- 反问澄清：只有第 3 条有明显模糊表达，不是主流错误。
